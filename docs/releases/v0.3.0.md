Codenotch for phone, for Codenotch for Mac 1.26.

## Before you install

**The Mac needs Codenotch with phone pairing switched on.** The official
Codenotch release ships with it off for now. Install Codenotch from
[mohammad-albarham/codenotch](https://github.com/mohammad-albarham/codenotch)
(the official app with pairing on) — see
[On your Mac](https://github.com/mohammad-albarham/codenotch-mobile#on-your-mac).
Then open **Settings › Phone › Connect a Phone…** on the Mac and scan the code.

**Had v0.2.0 or earlier?** Those builds were signed with a different key.
Uninstall once, then install this one. Updates install over the top from here
on.

## Install

- **Obtainium (updates itself):** add `https://github.com/mohammad-albarham/codenotch-mobile`.
- **By hand:** download `codenotch-v0.3.0-android.apk` below and open it. The
  `.sha256` file next to it lets you check the download.

## What's new

- Works with Codenotch 1.26: icons for its new providers (Copilot, Gemini API,
  Kimi, Grok, MiniMax, MiMo, OpenCode, Manual and more), and Antigravity's
  "Gemini Models" and "Claude and GPT models" limits shown as separate groups.
- Numbers read the way the Mac's do: `11% Used · 89% left`, tenths below 1%
  instead of a misleading 0%, `12k` for large counts, and amounts like `$14.28`
  in the Mac's own words rather than a raw count.
- A stale reading whose window reset long ago says when it reset
  (`Reset 21 Sep`) instead of "Resetting now".
- A phone removed on the Mac now says **No longer paired** with a **Pair again**
  button, instead of asking you to retry forever.
- Settings explains Manual readings alongside Official and Derived.
